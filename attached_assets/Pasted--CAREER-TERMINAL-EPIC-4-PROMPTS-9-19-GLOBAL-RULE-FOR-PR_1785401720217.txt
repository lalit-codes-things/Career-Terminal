# PROMPT 9 — PROVENANCE & VERSIONED FACTS

The repository already contains:

* `ExtractionRun`
* `FactObservation`
* `FactProvenance`
* provenance references
* `CanonicalCandidateIntelligence`

Do NOT recreate them.

Audit and consolidate the existing implementation into one authoritative provenance pipeline:

```text
Source
→ ExtractionRun
→ FactObservation
→ Provenance/Evidence
→ Canonical Intelligence
```

Ensure every machine-derived fact can identify:

* user
* source type
* source ID
* extractionRunId
* processor/model/version
* observedAt
* confidence
* evidence where appropriate

Preserve historical observations.

User corrections must create new authoritative evidence without destroying the original machine observation.

Do not confuse Gmail checkpoints with ExtractionRun.

Support resume and Gmail sources through the same provenance contract.

Add migration/backfill only where provenance is reliably known. Never fabricate historical provenance.

Add tests for:

* provenance linkage
* versioning
* user correction
* duplicate processing
* ownership
* missing/legacy provenance

Run typecheck/lint/tests.
